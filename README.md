# FileCraft — Privacy-First File Tools

Free online tools for PDF merging, image compression, resizing, and format conversion. **100% client-side** — your files never leave your browser.

## Tools

| Tool | Description |
|------|-------------|
| [Merge PDF](https://filecraft.tools/merge-pdf/) | Combine multiple PDFs into one, drag to reorder |
| [Compress Image](https://filecraft.tools/compress-image/) | Reduce JPG/PNG/WebP size with quality control |
| [Resize Image](https://filecraft.tools/resize-image/) | Resize to exact dimensions or scale by % |
| [Convert Image](https://filecraft.tools/convert-image/) | Convert between JPG, PNG, WebP formats |

## Why FileCraft?

- **No uploads** — all processing runs locally in your browser
- **No accounts** — start using tools immediately
- **No limits** — process as many files as you want
- **Free forever** — supported by optional donations

## Tech Stack

- Pure HTML/CSS/JS — no frameworks, no build step
- [pdf-lib](https://pdf-lib.js.org/) for PDF operations
- Canvas API for image processing
- Hosted on GitHub Pages
